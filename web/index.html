🏗️ Context Anchor Architecture 208 Tests Passing

The Nova Context Anchor pipeline operates as an external, source-grounded memory layer that decouples AI reasoning from raw prompt context limits:

1 LLM Extractor with Verbatim Source Quotes

Extracts decisions, commitments, and facts from conversation messages. Every record contains exact source text, message ID, and confidence score.

2 Temporal Supersession Graph

When a new decision overrides a past one on the same subject, the old decision is updated to SUPERSEDED with a pointer to the overriding record.

3 Hybrid Memory Retrieval

Combines deterministic subject key matching with semantic hash embeddings in SQLite, achieving sub-5 millisecond response times.

4 Claim Splitter & Cryptographic Audit Log

Breaks answers into atomic claims, checks each against retrieved anchors, and signs the verdict into a SHA-256 tamper-evident log.
