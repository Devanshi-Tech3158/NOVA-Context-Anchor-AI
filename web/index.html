🏗️ Context Anchor Architecture

Nova Context Anchor solves the critical problem of LLM hallucination and forgotten conversational facts through a 4-tier pipeline:

  • 1. LLM Extractor: Extracts facts, decisions, and commitments from conversation turns with verbatim source quotes.
  • 2. Temporal Supersession: Automatically marks outdated decisions as SUPERSEDED when new decisions are made.
  • 3. Hybrid Memory Retrieval: Combines exact subject lookup with semantic hash embeddings.
  • 4. Evidence Judge & Claim Splitter: Atomically labels claims as supported, contradicted, outdated, or unsupported.
